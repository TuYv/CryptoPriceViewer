# Crypto Price Viewer

[![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)](https://github.com/TuYv/CryptoPriceViewer)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

[English](./README.md) · [中文](./README-zh.md) · **日本語** · [한국어](./README-ko.md)

ツールバーのアイコンをクリックするだけで、登録したコインの価格を確認できる Chrome 拡張機能です。1つのコインをツールバーに固定すれば、開かなくても価格が見えます。暗号資産ニュースのタイムラインも付いています。

![マーケット](./store-assets/screenshots/en/1-market.png)

## 機能

**マーケット**
- コインごとにブランドカラーのタイルで表示し、下に直近7日間の値動きを描きます
- ツールバーに固定したコインは1行全体に表示されます
- タイトル横のボタンでタイル表示とリスト表示を切り替えられます。リストでは1行に1コインを表示し、固定したコインが先頭に来ます
- タイルはドラッグで並べ替えできます。各タイルの「⋯」メニューから固定、詳細、先頭に移動、削除ができ、削除は5秒以内なら元に戻せます
- 検索は入力に合わせて結果を表示し、↑↓で選択、Enterで追加できます
- CoinGecko の制限やオフラインのときも、前回の価格をその時刻と一緒に表示し続けます

**コインの詳細**
- 1日・7日・30日・90日・1年の価格チャート。期間中の最高値と最安値を表示し、マウスを乗せるとその時点の価格がわかります
- 時価総額、24時間出来高、流通量、過去最高値（と現在どれだけ下にあるか）、時価総額ランキング
- そのコインに関するニュース

**ツールバーのアイコン**
- 固定したコインの価格または24時間の騰落率を表示します
- 色は「値動きの色」の設定に合わせます。アイコンにマウスを乗せると、コイン名・価格・騰落率が表示されます
- 設定した間隔でバックグラウンド更新します

**ニュース**
- 日付ごとにまとめたタイムライン。マイリストのコインや特定のコインに関するものだけを表示できます
- 複数のサイトが同じ出来事を報じた場合は、最も早い1件だけを表示します
- 初めて開いたときに、アクセスするサイトを説明し、許可を得てから取得を始めます

**設定**
- 表示通貨：米ドル、人民元、ユーロ
- 言語：简体中文、English、日本語、한국어（初期設定はブラウザに合わせる）
- 値動きの色：赤が上昇・緑が下落、緑が上昇・赤が下落、赤が上昇・青が下落。初期設定は言語ごとの慣習に合わせます（日本語は国内の暗号資産取引所に合わせて緑が上昇）
- 外観：システム、ライト、ダーク
- 無料の CoinGecko API キーを設定すると、制限に当たりにくくなります
- コインのリストは、同じ Chrome アカウントでログインしたパソコン間で同期されます

## インストール

- **Chrome ウェブストア**：「Crypto Price Viewer」で検索してください。
- **自分でビルドする**（Node.js 22 以降が必要）：

  ```bash
  git clone https://github.com/TuYv/CryptoPriceViewer.git
  cd CryptoPriceViewer
  npm install
  npm run build
  ```

  `chrome://extensions` を開き、デベロッパーモードをオンにして「パッケージ化されていない拡張機能を読み込む」から `.output/chrome-mv3` フォルダを選びます。

0.1.x から更新すると、コインのリスト、固定したコイン、通貨、言語、更新間隔はそのまま引き継がれます。

## データの取得元

- **価格**：[CoinGecko](https://www.coingecko.com/) の公開 API
- **ニュース**：[PANews](https://www.panewslab.com/)、[Odaily](https://www.odaily.news/)、[Decrypt](https://decrypt.co/)。拡張機能は見出しとリンクだけを表示し、記事は元のサイトで開きます。記事の著作権は各サイトに帰属します。配信元は「設定 › ニュースの配信元」で個別にオフにできます。

## プライバシー

- 個人情報の収集・送信は一切なく、分析ツールや広告もありません
- 設定は Chrome 標準の同期ストレージに保存され、あなたの Chrome アカウント内でのみ同期されます
- CoinGecko API キーはこのパソコンにだけ保存されます
- 接続先は CoinGecko と、あなたが許可したニュースサイトだけです

詳しくは[プライバシーポリシー](./privacy-policy.html)をご覧ください。
